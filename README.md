# CCodeGenerator
Прототип генератора кода для преобразования графических блок-схем (в формате XML) в исполняемый C-код.

## Описание

Генератор:
1. Парсит XML-файл с описанием схемы.
2. Строит граф зависимостей.
3. Выполняет **топологическую сортировку** (алгоритм Кана) для определения порядка вычислений.
4. Генерирует **C-код**, аналогичный коду из примера в описании задачи

## Установка и сборка

### Требования
- C++ компилятор (`g++`, `clang++`)
- Библиотека **tinyxml2**

```bash
# Установка tinyxml2
# Ubuntu
sudo apt install libtinyxml2-dev
```
### Компиляция

```bash
g++ codegen.cpp -o codegen -ltinyxml2 -std=c++11
```
### Использование

```bash
./codegen <test.xml> <output.c>
